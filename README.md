# ClashCheck

Created by Tianqi Jiang.

ClashCheck is a simple Python timetable app that checks for overlapping events and short travel gaps. Add your events or click **Load Example**, then click **Check Timetable**.

## Run

Use Python 3 with Tkinter installed, download `ClashCheck.py`, then run:

```sh
python ClashCheck.py
```

No third-party packages are required.
